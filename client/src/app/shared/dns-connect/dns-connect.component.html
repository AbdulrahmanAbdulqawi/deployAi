In Cloudflare, go to My Profile → API Tokens → Create Token and start from the Edit zone DNS template. It needs exactly two permissions and one scope:

  1. Set each permission row's first dropdown to Zone — not Account. The Account group has a DNS section too, and none of it can read zones or change records.
  2. Grant Zone → Read (so DeployAI can see which domains you own) and DNS → Edit (so it can point them at your server).
  3. Set Zone Resources to Include → All zones, or pick out the specific domains you want DeployAI to manage.

Those two permissions are everything DeployAI uses — anything broader only widens what a leaked token could reach.
