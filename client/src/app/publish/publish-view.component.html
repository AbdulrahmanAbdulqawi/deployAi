What are connection settings?

Your website and your API run as two separate services. To work together, each one needs to know the other's current address:

  • Your website uses the API's address to load and save data.
  • Your API allows requests from your website's address so they aren't blocked.

This is usually handled automatically. You may need to reconnect when:

  • A service received a new address after a recent deployment.
  • You added or changed a custom domain.
  • Sign-in or data requests begin failing with connection or blocked-request errors.

Reconnecting re-verifies both addresses and links them to each other again.
