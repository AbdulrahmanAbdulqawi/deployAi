What are sync settings?

Your website and your API run on two different services. For them to work together, each one needs to know the other's current web address:

  • Your website needs the API's address so it can load and save data.
  • Your API needs to allow your website's address so requests aren't blocked.

Most of the time this is handled automatically. You may need to reconnect when:

  • You just deployed and a service got a new address.
  • You added or changed a custom domain.
  • Sign-in or data starts failing with connection or "blocked" errors.

Reconnecting re-checks both addresses and points them at each other again.
